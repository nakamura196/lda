地域文化資源
デジタルアーカイブ

谷根千エリアの地域文化資源（全 446 件）を IIIF Presentation API v2 で公開するデジタルアーカイブ。 国際的な相互運用規格に準拠し、画像・メタデータ・アノテーションをオープンに提供します。 Mirador / Universal Viewer などの IIIF 対応ビューワーから直接読み込めます。
